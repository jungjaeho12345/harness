# 기사작성기 클라이언트 — 배포 폴더 안내

이 문서는 클라이언트 배포 폴더에 동봉되는 안내서다. 기자·데스크 PC에서 이 폴더만으로 기사작성기를 쓸 수 있다.

## 1. 구성

```
기사작성기\
├─ 기사작성기.exe          ← 실행 파일 (더블클릭으로 시작)
├─ resources\              ← 프로그램 구성 파일
├─ locales\                ← 언어 파일
├─ *.dll · *.pak · LICENSE 등 ← 실행에 필요한 구성 요소 (지우지 말 것)
└─ README-배포-클라이언트.md ← 이 문서
```

- **이 프로그램은 서버에 접속만 한다.** 기사·계정·화면은 전부 서버에 있고, 이 폴더에는 데이터가 저장되지 않는다.
- 폴더 크기는 약 350MB다(압축 시 약 140MB).

## 2. 설치

- 압축을 풀어 원하는 폴더(예: `D:\기사작성기`)에 두면 끝이다. **설치 과정도, 관리자 권한도 필요 없다.**
- 폴더를 통째로 복사하면 다른 PC에서도 그대로 동작한다(포터블).
- 네트워크 드라이브·USB에서 실행하면 첫 기동이 느릴 수 있다 — 로컬 디스크 복사를 권장한다.

## 3. 최초 실행

1. `기사작성기.exe`를 더블클릭한다.
2. **서버 주소 입력 화면**이 뜬다. 서버 담당자에게 받은 주소를 입력한다.
   - 형식: `192.168.0.10:3001` (주소:포트. `http://`는 생략하면 자동으로 붙는다)
3. **[연결 확인]** 을 눌러 "연결 확인됨"이 나오는지 본다.
4. **[저장하고 시작]** 을 누르면 기사작성기 화면(로그인)이 열린다.

- **기사작성기 서버가 아닌 주소는 저장되지 않는다.** 프로그램이 서버 응답까지 확인한 뒤에만 저장한다.
- 저장 위치는 사용자 폴더(`%APPDATA%\기사작성기\config.json`)다. **PC 사용자마다 따로 저장**되며, 프로그램 폴더를 복사해도 설정은 따라가지 않는다.

## 4. 서버 주소 변경

- 메뉴 **`파일 > 서버 주소 변경`** 에서 언제든 바꿀 수 있다.
- 서버가 꺼져 있어 오류 화면이 떠 있을 때도 그 화면의 **[서버 주소 변경]** 버튼으로 바꿀 수 있다.
- **메뉴에는 단축키가 없다.** 기사 편집 단축키(Ctrl+Y, Ctrl+A, Alt+V 등)와 충돌하지 않게 한 의도적 설계다.

## 5. 새로고침·확대/축소

- 메뉴 **`보기`** 에서 클릭으로 한다: 새로고침 / 확대 / 축소 / 원래 크기.
- 새로고침해도 로그인은 유지된다(다시 로그인할 필요 없음).

## 6. 연결 실패 시

오류 화면이 원인 안내와 함께 뜬다. 원인별 대처:

- **주소를 찾을 수 없음** — 주소 오타 또는 사내 DNS 문제. 주소를 다시 확인한다.
- **연결 거부** — 서버가 꺼져 있거나 포트 번호가 다르다. 서버 담당자에게 확인한다.
- **도달 불가 / 시간 초과** — 네트워크 연결·방화벽을 확인한다.
- **서버는 응답하는데 화면이 안 뜸(404)** — 서버 배포 폴더에 화면 파일(`web\`)이 없는 상태다. 서버 담당자에게 알린다.

오류 화면의 **[다시 연결]** 로 재시도한다. 자동 재접속은 하지 않는다 — 버튼을 눌러야 다시 연결한다.

## 7. 알려진 제약

- **복사/붙여넣기(마우스 우클릭 메뉴)**: 서버 주소가 `127.0.0.1`(서버와 같은 PC)이면 정상이다.
  **LAN 주소(예: `192.168.x.x`)로 접속하면 목록 우클릭의 본문복사·제목만복사와 에디터의 일부 붙여넣기가 동작하지 않는다**
  — 암호화되지 않은(http) 원격 주소에서는 브라우저 엔진이 클립보드 기능을 잠그기 때문이다.
  키보드 Ctrl+C/Ctrl+V(문서 편집)는 이와 별개로 동작한다. 근본 해결은 서버의 HTTPS 적용(서버 담당자 소관)이다.
- **인쇄**: 편집 화면의 `파일 > 인쇄`(기사작성기 화면 안의 메뉴)는 인쇄 창을 띄우도록 만들어져 있으나,
  이 배포판에서는 실제 프린터 대화상자 동작의 최종 확인이 완료되지 않았다. 인쇄가 되지 않으면
  `파일 > 인쇄미리보기` 창에서 내용을 확인하고 서버 담당자에게 알려 달라.
- **편집 잠금**: 편집 중 창을 정상적으로 닫으면 잠금이 풀리는 것을 확인했다. 다만 강제 종료·PC 다운
  등에서는 잠금이 남을 수 있다 — 그때는 데스크(D)/관리자(Z)가 목록 우클릭의 **Lock해제**로 풀면 된다.
- **맞춤법 밑줄(빨간 줄)은 표시되지 않는다.** 외부 통신(사전 다운로드 등)을 만들지 않기 위해 브라우저
  맞춤법 검사를 끈 의도적 설정이다. 맞춤법 검사는 에디터 메뉴의 맞춤법 기능을 쓴다.
  (이 설정의 최종 유지 여부는 운영 확정 대기 항목이다 — 불편하면 서버 담당자를 통해 의견을 보내 달라.)
- **Alt 조합 단축키(Alt+Y·Alt+V·Alt+O)**: 프로그램 메뉴가 단축키를 일절 쓰지 않도록 만들어 충돌 표면을
  없앴으나, 실제 업무 PC에서의 최종 확인은 진행 중이다. 동작하지 않는 사례가 있으면 서버 담당자에게 알려 달라.
- **SmartScreen·백신 경고**: 서명되지 않은 실행 파일이라 처음 실행 시 경고가 뜰 수 있다 —
  "추가 정보 → 실행"으로 진행한다. 회사 배포 시에는 보안 담당자에게 예외 등록을 요청한다.
- **한 번만 실행된다**: 이미 떠 있는 상태에서 다시 실행하면 새 창이 뜨지 않고 기존 창이 사용된다.

## 8. 업데이트

- 자동 업데이트는 없다. 새 폴더를 받아 기존 폴더를 통째로 바꾸면 된다(설정은 `%APPDATA%`에 있어 유지된다).
- **기사작성기 화면(메뉴·편집기 등)의 변경은 서버만 갱신하면 자동 반영된다** — 이 프로그램을 다시 배포할
  필요가 있는 것은 프로그램 자체(창·메뉴·서버 연결 방식)가 바뀔 때뿐이다.

## 9. 문제 해결

| 증상 | 원인 | 조치 |
|------|------|------|
| 실행해도 흰 화면/빈 화면 | 서버는 응답하나 화면 파일(web\) 미배치 | 서버 담당자에게 알림 (6절 404 항목) |
| "서버에 연결할 수 없습니다" | 서버 미기동·주소/포트 오류·방화벽 | 주소 확인 → [다시 연결] → 서버 담당자 확인 |
| 로그인이 안 됨 | 계정 문제 또는 서버 설정(HTTP에서 보안 쿠키) 문제 | 계정은 데스크/관리자에게, 반복되면 서버 담당자에게 |
| 실시간 목록이 안 바뀜 | 서버와의 실시간 연결 끊김 | 목록 상태 표시 확인 → `보기 > 새로고침` → 계속되면 서버 확인 |
| 인쇄가 안 됨 | 프린터 미설정 또는 이 배포판의 인쇄 제약(7절) | 기본 프린터 확인 → 인쇄미리보기로 확인 → 담당자에게 보고 |
| 두 번 실행해도 창이 안 뜸 | 이미 실행 중(기존 창이 최소화/뒤에 있음) | 작업 표시줄에서 기사작성기 창을 찾는다. 없으면 작업 관리자에서 종료 후 재실행 |

## 10. 서버 담당자에게 물어볼 것

- 서버 주소와 포트 (예: `192.168.0.10:3001`)
- 내 계정(아이디/초기 비밀번호)과 권한(기자 R / 데스크 D / 관리자 Z)
- 서버 운영 가이드 위치: 서버 배포 폴더의 `README-배포.md`
