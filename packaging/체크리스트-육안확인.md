# 기사작성기 클라이언트 — 사용자 육안 확인 체크리스트

자동 검증(`npm run verify:integration`)이 **원리상 판정할 수 없는** 항목만 모았다.
실제 업무 PC에서 항목별로 절차를 따라 하고 결과 칸에 `정상` / `제약 있음` / `미확인` 중 하나를
적어 담당자에게 회신해 달라. 각 항목의 괄호 줄은 자동화가 불가능한 이유다.

전제: 서버가 기동돼 있고, 클라이언트가 LAN 주소(예: `http://192.168.x.x:3001`)로 설정·재시작을
마친 상태에서 시작한다(통합 가이드 4~5절).

| # | 항목 | 절차 | 기대 결과 | 결과 |
|---|------|------|-----------|------|
| 1 | 인쇄 대화상자 | 기사 편집 화면에서 `파일 > 인쇄` | Windows 인쇄 대화상자가 뜬다 | |
| 2 | 인쇄 미리보기 | `파일 > 인쇄미리보기` | 새 창에 기사 내용이 그려진다 | |
| 3 | Alt 조합 단축키 | 편집 중 `Alt+Y`((끝) 삽입) · `Alt+V`(원본 붙여넣기) · `Alt+O`(약물입력) | 세 키 모두 편집 기능이 동작하고, 메뉴바가 대신 활성화되지 않는다 | |
| 4 | Ctrl+R / F5 | 목록 화면에서 `Ctrl+R`, 그다음 `F5` | Ctrl+R는 새로고침된다(로그인 유지). **F5는 아무 반응이 없는 것이 현재 사양이다** | |
| 5 | 한글 IME | 편집기에서 한글 조합 입력·조합 중 백스페이스·조합 중 엔터 | 글자 깨짐·중복 입력 없이 정상 입력된다. **맞춤법 빨간 밑줄은 없는 것이 정상**(확정 예외 — 맞춤법은 에디터 메뉴) | |
| 6 | 클립보드 실사용 | 목록 우클릭 `본문복사` → 메모장에 붙여넣기 / 에디터 우클릭 붙여넣기 / 스크린샷 이미지 붙여넣기 | 세 경로 모두 동작한다(LAN 주소 접속 상태에서) | |
| 7 | 최초 설정 직후 재시작 | 설정 없는 PC(또는 `%APPDATA%\기사작성기` 삭제가 아닌 **새 사용자 계정**)에서 LAN 주소 첫 저장 | 저장 직후 재시작 안내가 뜬다. 재시작 **전**에는 6번 항목이 막히고, 껐다 켠 **후**에는 된다 | |
| 7b | config.json 사전 배치 | config.json을 미리 배치한 PC에서 첫 실행 | 주소 입력 화면 없이 바로 열리고, **재시작 없이** 6번 항목이 된다 | |
| 8 | 주소 변경 후 재시작 | `파일 > 서버 주소 변경`으로 **다른** LAN 주소 저장 | 재시작 안내가 뜨고, 재시작 전에는 새 주소에서 클립보드가 막히며 재시작 후 풀린다 | |
| 9 | 아이콘·버전 | 탐색기에서 exe 아이콘 확인(아이콘 캐시 주의 — 폴더를 새 위치로 복사해 확인) + 작업표시줄 아이콘 + `도움말 > 정보` | 새(파란 도형) 아이콘이 보이고, 정보 대화상자 버전이 1.0.0이다 | |
| 10 | 상세보기 팝업 육안 | 목록에서 이미지·유튜브 임베드가 있는 기사 행 클릭 | 720×800 창에 공통정보·본문·이미지·유튜브 영상이 표시된다 | |
| 11 | 외부 링크 | 상세보기 창의 외부 링크 클릭 | **기본 브라우저**로 열린다(앱 창 안에서 열리면 정책 오류 — 즉시 보고) | |
| 12 | 창 배치 저장 | 창 크기 변경(또는 최대화) 후 종료 → 재실행 | 마지막 크기·최대화 상태로 복원된다 | |
| 13 | 두 번째 실행 | 프로그램이 떠 있는 상태(최소화 포함)에서 exe를 다시 실행 | 새 창이 뜨지 않고 기존 창이 앞으로 나온다 | |
| 14 | SmartScreen | 다른 PC에 폴더를 처음 복사해 실행 | 경고가 뜨면 "추가 정보 → 실행"으로 진행된다. 경고 유무와 문구를 기록 | |

자동화 불가 사유(항목 번호):

- 1·2: OS 인쇄 대화상자·프린터 드라이버는 프로그램 밖 창이라 자동 판정 수단이 없다.
- 3·4·5: 실제 키보드·IME 입력은 사람의 물리 입력이 필요하다(합성 입력은 메뉴바·IME 경로를 그대로 재현하지 못한다).
- 6: 자동 검증은 클립보드 기능의 존재까지만 판정한다(비표시 검증 창은 포커스가 없어 실제 왕복이 거부된다). 실제 복사·붙여넣기는 사람 확인 몫이다.
- 7·7b·8: "재시작 전에는 안 되고 후에는 된다"는 프로그램 껐다 켜기를 사이에 둔 관찰이라 사람 확인이 필요하다.
- 9: 탐색기·작업표시줄 아이콘 렌더는 Windows 셸(아이콘 캐시 포함) 소관이다 — 파일 안의 아이콘 데이터는 자동 검증됐다.
- 10: 이미지·영상의 실제 픽셀 표시는 자동 단언 대상이 아니다(창 크기 720×800과 본문 텍스트는 자동 검증됐다).
- 11~14: OS 셸(기본 브라우저·작업표시줄·SmartScreen)과 프로세스 재실행을 넘나드는 동작이다.

**이상 발견 시 DB를 직접 고치지 말고 담당자에게 보고해 달라.**
(편집 잠금이 남은 기사도 DB가 아니라 목록 우클릭의 Lock해제(데스크/관리자)로 푼다.)
