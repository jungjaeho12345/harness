## 배경 (실코드 확인 결과)

- 단어 선택 헬퍼는 줄 요소의 **첫 자식**만 보고, 그것이 텍스트 노드가 아니면 즉시 반환하며, 열 값도 **첫 자식 길이**로 clamp한다.
- 맞춤법 하이라이트가 켜지면 줄 요소는 `[텍스트, 스팬, 텍스트, …]`가 된다(phase 39 렌더). 그래서:
  - **변형 A**: 첫 단어가 하이라이트면 첫 자식이 요소라 즉시 반환 → 그 줄은 단어 선택 자체가 불가능.
  - **변형 B**: 하이라이트 뒤쪽 단어를 가리키면 열이 첫 자식 길이로 접혀 시작=끝 → **조용한 no-op**.
  - **변형 C**: 하이라이트가 단어를 일부만 덮으면 잘린 범위만 선택된다.
- 호출부는 줄 전체 텍스트 기준의 열을 준다(본문 평문에서 계산) — 즉 **좌표계는 이미 옳고, 적용기만 틀렸다**.

## 작업

TDD 순서를 지킨다: **먼저 red 테스트 → 그다음 구현**.

### A. red 테스트 추가 (`web/src/view/editorSelect.test.js`)

단어 선택 describe에 **여러 노드로 구성된 줄**을 쓰는 케이스를 추가한다. 테스트 DOM은 실제 렌더 형태를 그대로 흉내 낸다(줄 요소 안에 텍스트 노드 → 하이라이트용 스팬 → 텍스트 노드). 기존 5케이스는 수정 금지.

1. **하이라이트 뒤쪽 단어 선택** — 스팬 뒤 텍스트에 있는 단어의 줄-로컬 범위를 넘긴다. 기대: 선택 문자열이 그 단어와 정확히 같다(수정 전에는 빈 선택 → red).
2. **첫 단어가 하이라이트인 줄** — 줄 요소의 첫 자식이 스팬인 DOM에서 첫 단어 범위를 넘긴다. 기대: 그 단어가 선택된다(수정 전에는 즉시 반환 → red).
3. **경계를 걸친 단어** — 하이라이트가 단어의 일부만 덮어 범위가 스팬 안팎에 걸치는 경우. 기대: 단어 전체가 선택된다(선택 문자열 비교로 단언).
4. **clamp 기준이 줄 전체 길이** — 끝 값이 줄 길이를 넘어가도 줄 끝까지 선택된다(단일 노드 케이스의 기존 계약과 동형).
5. **no-op 계약 유지** — 빈 범위(시작=끝)·텍스트가 하나도 없는 줄·범위 밖 줄 인덱스·`null` 루트에서 예외 없이 선택이 변하지 않는다.
6. **DOM 불변 잠금** — 위 다중 노드 케이스 실행 후에도 줄 요소의 마크업이 그대로다(선택 연산만 한다는 파일 상단 CRITICAL의 증거).

### B. 구현 (`web/src/view/editorSelect.js`)

- 단어 선택 함수 안에서 줄 요소의 **자손 텍스트 노드를 document 순서로 순회**하며 길이를 누적해, 줄-로컬 열을 `(텍스트 노드, 노드-로컬 오프셋)`으로 환산하는 지역 헬퍼를 만든다.
- 환산 규칙(캐럿 읽기 쪽 계약과 동형):
  - clamp 기준은 **줄 요소 전체 텍스트 길이**다(첫 자식 길이 아님).
  - **시작점**은 누적 구간 안쪽(구간 경계에 걸리면 그 구간의 시작 쪽)으로 잡는다.
  - **끝점**은 구간 경계에 걸리면 **앞 노드의 끝**으로 잡는다 — 그래야 경계에서 범위가 접히지 않는다.
  - 텍스트 노드가 하나도 없으면 오늘처럼 no-op.
- 시작·끝이 **서로 다른 노드**를 가리키는 것을 허용한다(범위 설정 두 호출을 각각의 노드/오프셋으로 한다).
- 빈 범위(시작 ≥ 끝)·범위 밖 줄 인덱스·`null` 루트의 no-op 판정과, 선택 적용 함수 재사용은 **오늘 형태를 유지**한다.
- 함수 주석에 새 좌표 계약(줄 전체 텍스트 기준·다중 노드 허용)과 그 이유(하이라이트가 줄을 쪼갠다)를 한두 문장으로 남긴다.
- 다른 선택 함수(전체·한줄·문단)는 **한 줄도 바꾸지 마라** — 그들은 노드 단위가 아니라 노드 경계로 범위를 잡아 이 하자와 무관하다.

### C. 기존 테스트 이름 정정 (선택적, 단언 변경 금지)

기존 케이스 중 clamp 기준을 "텍스트 노드 길이"로 서술한 이름(`editorSelect.test.js` 122행 부근)은 새 계약(**줄 전체 텍스트 길이**)과 어긋난다. **이름 문자열만** 계약에 맞게 고치는 것을 허용한다 — 단언·입력·기대값은 **한 글자도 바꾸지 마라**(단일 노드 줄에서는 두 기준이 같은 값이라 그 케이스는 그대로 green이어야 한다). 이름을 고쳤다면 요약에 "이름만 정정, 단언 무변경"이라고 명시하라.
